# License sources

These files are exact copies from the Cargo packages in the configured SDK's
Bazel dependency closure. Versions appear in directory names and in
`THIRD_PARTY_NOTICES.md`. Build-time procedural macro dependencies are included.

`rust-1.97.0/COPYRIGHT-library.html` comes from the pinned Rust toolchain's
`share/doc/rust/` directory and includes standard-library dependency notices.
Refresh these copies when changing the SDK's Rust dependency or toolchain pins.
