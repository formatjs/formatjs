## Usage

### Simple

```tsx
match(['fr-XX', 'en'], ['fr', 'en'], 'en') // 'fr'

match(['zh'], ['fr', 'en'], 'en') // 'en'
```

### Supported locale filtering

`LookupSupportedLocales(availableLocales, requestedLocales)` returns supported
requested tags in their original order, preserving region subtags and Unicode
extensions even when matching falls back to a parent locale.

```tsx
LookupSupportedLocales(['de'], ['de-AT-u-co-phonebk']) // ['de-AT-u-co-phonebk']
```

Locale resolution uses an internal record isolated from inherited extension-key
setters on `Object.prototype`.

Locale matching extracts only the Unicode `u` extension. Private-use subtags
remain intact, including text resembling `u-co-phonebk`; trailing extensions
are preserved separately from Unicode keywords.

### Best-fit matching

Best fit follows ICU4C/J defaults using generated CLDR language distances.
It respects requested-locale priority, directional language fallbacks, regional
clusters, and likely-subtag ties. Unacceptable matches return `defaultLocale`.
Lookup matching remains available with `{algorithm: 'lookup'}`.

```tsx
match(['br'], ['de', 'fr'], 'de') // 'fr': Breton can fall back to French
match(['fr'], ['de', 'br'], 'de') // 'de': reverse fallback is not allowed
match(['en-GB', 'sv'], ['en', 'sv'], 'en') // 'en': earlier regional match wins
```

Matching caches supported lists and repeated requests. Reuse supported arrays
when possible; array and Set content changes invalidate the relevant caches.
The host or polyfilled `Intl.Locale` supplies canonicalization and likely subtags.

Measured 2026-10-31 on Apple M4 Max, macOS arm64, Node 24.14.0 / ICU 78.2; source `56d15e997`. Median of seven warmed rounds.

| best fit en-XZ      |        456,567 |             72,177 |            — |

Polyfill uses host Intl helpers; Full helpers installs all FormatJS Intl APIs.
Module loading and data registration are excluded. Construction rows include
`resolvedOptions()`. These are desktop microbenchmarks; native locale data may
differ. † marks noisy rows (round max/min > 1.5). See [workloads, commands, and raw results](https://github.com/formatjs/formatjs/tree/main/benchmarks/polyfills).
