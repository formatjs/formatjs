# Difference option spelling and private unit indexing

Reviewed 2026-11-22. Requested authority remains [ECMA-262](https://tc39.es/ecma262/), whose current published text has no Temporal API chapters. Temporal clauses below are separately rendered proposal comparisons; no authority substitution or completed-method credit.

## Reproduced defects

PlainDate, PlainDateTime and ZonedDateTime converted `largestUnit` to a string, then deferred vocabulary validation until after roundingIncrement, roundingMode and smallestUnit. An unknown spelling combined with a throwing roundingIncrement getter propagated that getter's sentinel instead of rejecting the spelling first. The public regression failed before correction.

PlainDate also computed an automatic largest unit using index −1 for a recognized time-valued smallestUnit. An inherited `Array.prototype['-1']` getter ran before its intended RangeError. A separate public regression observed one hook call before correction. Both until and since share the affected function; native data builds use the same JavaScript preparation before dispatch.

## Numbered comparison and current source

[Proposal §13.43 GetDifferenceSettings](https://tc39.es/proposal-temporal/#sec-temporal-getdifferencesettings) distinguishes vocabulary validation during reads from later category validation. Instant172, PlainTime320 and PlainYearMonth193 already perform early vocabulary validation. Shared controls include these unaffected callers to preserve consistent observable behavior. Their complete methods are not signed off here.

The exercised language leaves remain [ECMA-262 §7.1.19 ToString](https://tc39.es/ecma262/#sec-tostring), [§7.1.1 ToPrimitive](https://tc39.es/ecma262/#sec-toprimitive) and [§7.3.2 Get](https://tc39.es/ecma262/#sec-get-o-p). Source uses existing ToString/unitOption and ordinary property reads; no replacement conversion or general language implementation added. The option comparison's allowed-value operation is [ECMA-402 §9.2.11 GetOption](https://tc39.es/ecma402/#sec-getoption), limited to this exercised dependency.

## Controls and validation

[Shared spelling controls](../../packages/temporal/tests/public-calendar-oracle.ts#L192) cover all six difference APIs, until/since, equal/unequal operands, four invalid spellings and a string-hint coercion trace. Later getter sentinel must remain unobserved for invalid spelling. Recognized names, plural names, auto and undefined preserve subsequent getter behavior. An additional trace reaches a throwing smallestUnit getter after increment/mode coercion, preventing an incorrect eager category check.

[Private-index control](../../packages/temporal/tests/public-calendar-oracle.ts#L161) temporarily installs the negative-key getter and restores its exact original descriptor in finally before assertions. It requires zero hooks and RangeError for both date methods.

Controls run in public_calendar_test, source/bytecode public_calendar_hermes_oracle_test, and native_iso_hermes_oracle_test after native configuration. Independent calendar-policy reference fixtures are unchanged. Five focused gates pass (three executed, two cached).
