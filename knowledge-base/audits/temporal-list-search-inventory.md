# Private array search audit

Reviewed 2026-11-21. Implementation dependency inventory for the Temporal spec audit.
All 74 remaining classified array searches below retain their realm's original Array
`includes`/`indexOf` and Reflect.apply. Five locale-matcher calls use local captures
to preserve dependency direction; the other 69 use ECMA-262 shared captures.

The original search pass replaced 76 calls. Locale-list entry classification now
uses IsObject directly, removing one search. Exact unit-name pair matching removes
one more; this inventory tracks the 74 retained calls.

`includes` retains SameValueZero; `indexOf` retains strict equality, first-match
indices and sparse-slot behavior. Six public/provider mutation cases and native
Hermes reproduced the gap before the fix. Existing public getters and Proxy
property semantics remain those of the original intrinsics. These private list
queries do not sign off their callers' field conversion or calendar algorithms.

AST classification covered Temporal, ECMA-262/402 abstract helpers and the
DateTimeFormat, DurationFormat, getCanonicalLocales and locale-matcher providers.
The remaining 55 direct searches in that scope have string receivers and remain
open. Other methods, iterators, initialization under already-modified primordials
and cross-realm requirements remain separate audit work.

Locations refer to the reviewed source. Each column links to the corresponding
captured helper call, not its import. Update this inventory when those calls move.
