# PlainYearMonth difference caller contract

Reviewed 2026-11-22. Requested [ECMA-262](https://tc39.es/ecma262/) has no Temporal API chapters. Numbered Temporal clauses below use the separately rendered proposal for comparison/navigation only. No full-method or authority signoff.

Comparison: [§9.5.7 DifferenceTemporalPlainYearMonth](https://tc39.es/proposal-temporal/#sec-temporal-differencetemporalplainyearmonth); public [§9.3.16 until](https://tc39.es/proposal-temporal/#sec-temporal.plainyearmonth.prototype.until) and [§9.3.17 since](https://tc39.es/proposal-temporal/#sec-temporal.plainyearmonth.prototype.since).

## Reproduced private-field defect

Private `dateFields` records have own year/month/monthCode/day, with no era fields. Difference formerly spread those records into ordinary objects. `yearMonthFields` calls `resolveCalendarYear`, whose era reads could invoke inherited Object.prototype getters for Gregorian and other non-ISO calendars. Two branded operands therefore reached unrelated public hooks. The regression observed one inherited era call before correction.

Both [reference copies](../../packages/temporal/plain-year-month.ts#L233) now have null prototypes. Own private fields and provider calculation order remain unchanged. Public bags still go through ordinary inherited field Gets; the shared positive control requires inherited era and eraYear getters exactly once. Native dispatch bypassed the faulty TS copies; its controls verify parity.

## Reference dates and controls

Constructor ISO reference day is distinct from visible calendar fields. Gregorian Jan31→Feb29 normalizes to Jan1→Feb1, so unrounded until/since retain ±P1M. Hebrew5784 M05L→M06 likewise spans one calendar month. Expand with increment2 yields ±P2M. Same visible Gregorian January with references15/16 normalizes to the same first day and returns PT0S even though stored dates differ.

[Shared controls](../../packages/temporal/tests/public-calendar-oracle.ts#L118) exercise those literals under separate era/eraYear poisons. Descriptors restore before assertions or result formatting. Positive public inherited-era conversion remains observable. TS, source/bytecode Hermes and configured native transport execute the helper; independent reference oracle remains unchanged.

Lower-bound distinction remains intentional: YearMonth permits April−271821 references that cannot become a full PlainDate on April1. Exact self difference may return zero after settings, while differing references can require normalization and reject. Existing range/short-date evidence does not become full public bound signoff here.
